
# 📘 Atividade: Jogo da Forca em Python

## 🎯 Objetivo

Construa um jogo da Forca em Python para praticar manipulação de strings, loops, condicionais, entrada de dados e seleção aleatória.

## 📝 Tarefas

### 🛠️ Selecionar e Ocultar uma Palavra

#### Descrição
Prepare o início do jogo selecionando uma palavra aleatoriamente e exibindo seu progresso oculto para o jogador.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Exibir uma posição oculta para cada letra da palavra, no formato `_ _ _`.

### 🛠️ Implementar os Palpites e o Fim do Jogo

#### Descrição
Permita que o jogador tente adivinhar a palavra informando letras. Atualize o progresso e encerre a partida quando a palavra for descoberta ou as tentativas incorretas acabarem.

#### Requisitos
O programa concluído deve:

- Aceitar palpites de letras e revelar no progresso as posições correspondentes às letras corretas.
- Rastrear e exibir o número de tentativas incorretas restantes.
- Encerrar a partida quando a palavra for adivinhada ou quando as tentativas incorretas se esgotarem.
- Exibir uma mensagem de vitória ou derrota, conforme o resultado.
